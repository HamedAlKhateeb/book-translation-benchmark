# 📚 منظومة تقييم ومقارنة ترجمة الكتب (Book Translation Benchmark & Quality Evaluation)

تطبيق ويب متكامل لمقارنة وتقييم الترجمة الآلية بالترجمة البشرية الاحترافية للكتب والروايات والمقالات، مع دعم استخراج الفصول من صيغ متعددة، ومحاذاة الفقرات ديناميكياً، وتشغيل نموذج **COMET** العصبي، وحساب معايير **MQM**، **chrF++**، و **BLEU**، مع مصادقة مستخدمين وقاعدة بيانات سحابية عبر **Firebase**.

---

## 🌟 المميزات الرئيسية

1. **دعم استخراج الفصول تلقائياً**:
   * يدعم صيغ: `EPUB`, `DOCX`, `HTML`, `Markdown` (`.md`, `.txt`).
   * تنظيف النصوص من علامات التوجيه الخفية وتطبيع الحروف العربية.
2. **المحاذاة الديناميكية للفقرات (Dynamic Paragraph Alignment)**:
   * التغلب على تباين دمج وتقسيم الجمل بين المترجم البشري والآلة بواسطة البرمجة الديناميكية ومكتبة `rapidfuzz` (`max_merge = 4`).
3. **محرك المقاييس المتقدمة**:
   * **COMET (`Unbabel/wmt22-comet-da`)**: التقييم العصبي الدلالي الأقرب للتقييم البشري.
   * **chrF++**: التقييم المورفولوجي الأنسب للغة العربية على مستوى الأحرف والكلمات.
   * **BLEU**: التطابق اللفظي المباشر.
   * **إطار MQM (Multidimensional Quality Metrics)**: تصنيف الأخطاء (دقة، مصطلحات، سلاسة، أسلوب)، وحساب نقاط العقوبة ودرجة الجودة لكل 100 كلمة.
4. **تكامل كامل مع Firebase**:
   * **Firebase Authentication**: تسجيل الدخول بالبريد الإلكتروني أو حساب Google.
   * **Cloud Firestore**: حفظ تاريخ التقييمات والجلسات سحابياً لكل مستخدم.
5. **تصدير التقارير**:
   * تصدير جداول تفصيلية وملخصات إحصائية بصيغة CSV تدعم اللغة العربية في Excel بترميز `UTF-8 with BOM` (`utf-8-sig`).

## 🚀 التشغيل المحلي (Quick Start)

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل تطبيق الويب:
```bash
python app_benchmark_web.py
```

افتح المتصفح على:
```
http://localhost:8080
```

---

## ☁️ معمارية الرفع على الإنترنت (Deployment Guide)

### 1. الواجهة الأمامية و Firebase:
* واجهة التطبيق مدمج بها إعدادات مشروع Firebase (`myreports-system`).
* تتيح للمستخدمين تسجيل الدخول واسترجاع سجل التقييمات في أي وقت.

### 2. الواجهة الخلفية لحساب COMET (Backend):
* نظراً لأن نموذج COMET يعتمد على شبكة عصبية (~2.3 جيجابايت PyTorch)، فإن أفضل الخيارات لنشر الباك إند أونلاين:
  1. **Hugging Face Spaces (الأسهل والمجاني)**: يدعم تشغيل كود بايثون مع نماذج PyTorch ونموذج COMET برابط عام ومستودع Git مجاني.
  2. **Google Cloud Run / Render / Railway**: تشغيل التطبيق كـ Docker Container.
